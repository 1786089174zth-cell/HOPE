# Jiayi model_14600（非 GRU）同一 120 球对照

> **历史错误适配记录，不能作为原生 14600 的行为对比。** 本文原测试把 GRU 的 `current racket / zero velocity / time_to_strike=-1` 中性目标用于 14600 待机，造成初始抽搐和漂移。模型权重身份正确，但运行时待机契约错误。已按教授远端源码修正并重跑，当前有效结果见 [model14600-corrected.md](model14600-corrected.md)。旧视频 `model14600-directional-120-dropout.mp4` 已弃用；旧数值仅供问题复现。

## 模型身份与接口

只读提取 `dongc1/nohope` 的 `main`，确定提交为 `7990f18c2c1ae560c9e0708dca10228b9f2cc610`。模型是 `hope_training/whole_body_tracking/checkpoints/policy.onnx`，而不是名字为 model14600 的新目录；其 ONNX SHA-256 为 `a987240610bb9a49ea42da8eafcdc84c3cfbc8d5470bf7ff1a2d7f1f624cdd28`，与仓库内 model_14600 训练来源记录和当前公开 HOPE 基准文件一致。checkpoint SHA-256 为 `20053e683cdbefb24575299b8b2b5c3d0890e145d96fa2cc543136983455f0e1`。部署 YAML 按 LF 规范化后 SHA-256 为 `c6f60914d30c688ec1f262bdb048eba234aa032ed2c094998ce8d4dcf46a3632`；Windows 检出为 CRLF，因此文件字节哈希与规范化哈希不同。

原始 ONNX 输入是 `obs[1,110]` 和参考动作索引 `time_step[1,1]`，动作输出为 `actions[1,31]`，其余输出为参考动作数据。检查 actions 的图依赖后确认：没有 GRU/LSTM/RNN/Scan/Loop 节点，actions 不依赖 time_step。64 组输入与原部署 OnnxPolicy 包装器做独立 SDK/训练关节顺序对照，最大动作误差为 0；改变 time_step 后动作误差也为 0。原始权重完全保留，没有重导出网络或人为加入隐藏状态。正式 trace 的 hidden_norm 全部为 null。

保留 14600 原部署的默认关节姿态、动作偏置/尺度/限幅和被动头关节反馈，初始 pelvis 为其原资产 `(0,0,1.0684)` 与单位旋转。Kp 与 YAML 按关节名称映射后相同；使用 ONNX 中的总训练阻尼（部署 Kd 加 MJCF 被动阻尼），在 MuJoCo 中仅应用一次。armature、friction 和机器人碰撞几何取共同 MJCF；Jiayi 和本测试的 MJCF Git blob 均为 `ef0259258a5060a55f934910665025f2c8ad2015`。19000/29999 的训练保存姿态/动作偏置与 14600 不同，本次没有用 GRU 的偏置替换 14600。

接口核验见 [model14600-verification.json](model14600-verification.json)。5 球接入预检得到 5 球发出、2 次球拍接触、0 摔倒、0 数值错误；其中第 9 球在原始记录中没有规划目标，因此只有 4 个接受命令，原有严格 integration_preflight_pass 为 false。本次将它作为接入/站立检查记录，没有将其报告为严格接球预检通过。

## 范围与复现

该对照检验共同规划目标与观测故障条件下各训练策略的行为；保留模型原生默认姿态，但未复现各自完整训练 curriculum 或原生部署生命周期。它不是只改变 GRU 的消融实验，也没有重新验证实时规划器对动捕断流的决策或实机安全。前 20 s 无球等待中的较大漂移同样保留在结果和录像中。

使用同一 MuJoCo/ONNX Runtime 环境。prepare 脚本额外需要 `onnx==1.19.1` 检查原图依赖，运行推理不需要修改网络：

```bash
python hope_training/whole_body_tracking/scripts/prepare_model14600_eval.py \
  --policy hope_training/whole_body_tracking/checkpoints/policy.onnx \
  --deploy hope_training/whole_body_tracking/checkpoints/deploy.yaml \
  --output /home/rog/hope-evaluations/model14600-native-bundle-v1
python hope_training/whole_body_tracking/scripts/run_model14600_directional.py \
  --bundle /home/rog/hope-evaluations/model14600-native-bundle-v1 \
  --output-root /home/rog/hope-evaluations/model14600-directional
```

输出目录必须是新目录。录像只从已记录的实际状态离线生成，保持与前两组相同的相机、800×500、20 fps 和 1 倍速；本次关闭装饰性阴影/地面反射，并移除遮挡画面的通用目标大字标记，这些显示设置不参与物理或评分。字幕明确标记 NON-GRU。
