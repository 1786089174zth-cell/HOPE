# Repair of the stalled world-model experiment — 2026-10-24

The failed run `7769htug` regressed after actor updates began: its mean episode
duration fell from 1.27 s during warmup to approximately 0.50 s near iteration
3000. All four event-ledger hit, motion-completion and home/HOLD counts remained
zero. Its learned observation transition also violated exact action-feedback
semantics, and it underestimated terminal-step penalties in frozen replay.

## Final implementation

The final learner identifies itself as `supermimic_hope_real_anchored_v2`.
It is a **hybrid adaptation**, not upstream pure SuperMimic:

- Action feedback is copied exactly with the correct action gradient.
  Announced references, target velocity/normal and clocks follow the recorded
  packet schedule. Future physical states, reset states and new packets are
  excluded from that conditioning.
- Five physical failure margins are captured before auto-reset and supervised
  even on failing transitions. Thresholds and terminal-cost weights come from
  the resolved original task. Collection checks every margin predicate and
  terminal-cost reconstruction against the environment. Smooth failure
  boundaries affect imagined gradients only; real rewards are unchanged.
- Value targets use actual replay rewards. Actor updates combine a clipped
  real-data surrogate (weight 1), model BPTT (weight 0.1), an explicit Gaussian
  behavior-KL penalty (weight 1), and the original sensor-noise regularizer.
  Recorded likelihoods use pre-projection actions and exclude passive heads.
- Policy replay uses the most recent 16 real vector steps. World-model fitting
  uses the full buffer. Episode resets stop real value bootstrapping; packet
  boundaries retain their value bootstrap. Imagined survival weights have no
  gradient shortcut that erases future costs.

The real task, question bank, PPQ004 physics and sensor-noise coefficient are
unchanged. The actor remains 110-D with 31 outputs. Five privileged failure
margins increase the world-model state from 438 to 443 dimensions; they never
enter the actor. Original user checkpoints were preserved. Training resume
remains unsupported; the fresh command is in the [README](../README.md).

An explicit behavior constraint was necessary: earlier bounded trials that
only corrected observation/terminal modeling, or only added clipped real
gradients, still regressed. Surrogate clipping does not itself constrain a
separate model-gradient objective.

## Validation

- 44 tests passed, including existing sensor-noise/recovery regressions and
  counterexamples for incorrect model rewards, stale replay, reset leakage,
  simultaneous terminal penalties, raw-action likelihoods and behavior drift.
- Final real MuJoCo-Warp test: **6144 environments, batch 2048, 800 iterations**,
  including 600 actor updates and 12,484,608 real transitions. This was a bounded
  offline validation run, not a user-owned training restart.
- Exact action-feedback and command-context errors remained zero. Physical
  failure predicates and reward decomposition matched the unmodified task on
  every collected step. The resolved task hash matches the failed user run.
- Both `model_500.pt` and `model_800.pt` contain finite model/optimizer tensors.
  W&B's offline datastore contains exactly 800 increasing history rows and the
  final checkpoint summary. No data was uploaded or backfilled.

**Four-stroke hit, motion-completion and home/HOLD counts are still zero in this
